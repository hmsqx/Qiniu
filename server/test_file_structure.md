# 新的文件结构测试示例

## 文件组织结构

现在预览图片和模型文件将放在同一目录下，使用相同的文件名但不同的后缀：

```
/root/Qiniu/server/model/
├── obj/
│   ├── 1704067200000_1234.obj      # 模型文件
│   ├── 1704067200000_1234.jpg      # 预览图片
│   ├── 1704067200001_5678.obj
│   └── 1704067200001_5678.jpg
├── fbx/
│   ├── 1704067200002_9012.fbx
│   └── 1704067200002_9012.jpg
├── glb/
│   ├── 1704067200003_3456.glb
│   └── 1704067200003_3456.jpg
├── stl/
│   ├── 1704067200004_7890.stl
│   └── 1704067200004_7890.jpg
├── usdz/
│   ├── 1704067200005_2345.usdz
│   └── 1704067200005_2345.jpg
└── mp4/
    ├── 1704067200006_6789.mp4
    └── 1704067200006_6789.jpg
```

## HTTP访问示例

### 模型文件访问
- `http://localhost:8080/model/glb/1704067200003_3456.glb`
- `http://localhost:8080/model/obj/1704067200000_1234.obj`
- `http://localhost:8080/model/fbx/1704067200002_9012.fbx`

### 预览图片访问
- `http://localhost:8080/model/glb/1704067200003_3456.jpg`
- `http://localhost:8080/model/obj/1704067200000_1234.jpg`
- `http://localhost:8080/model/fbx/1704067200002_9012.jpg`

## 优势

1. **文件组织更清晰**：相关文件放在同一目录下
2. **命名更一致**：模型文件和预览图片使用相同的基础文件名
3. **访问更简单**：可以通过文件名轻松找到对应的预览图片
4. **维护更容易**：删除模型时，对应的预览图片也在同一目录下

## 注意事项

1. 确保所有格式目录存在且有写权限
2. 预览图片统一使用.jpg格式
3. 文件名使用时间戳+随机数确保唯一性
4. 静态文件服务已配置支持所有相关文件类型
